# 日割時間チェッカー

ATND 勤怠ページ（`https://atnd.ak4.jp/ja/attendance`）向けの Chrome 拡張機能です。  
残り月間所定不足時間を、今月の残り平日日数で割った **1日あたり必要時間** を表示します。

## 機能

- 残り月間所定不足時間の自動取得
- 祝日 API を使った残り平日日数の計算（土日・祝日除外）
- 今日の退勤打刻状況に応じた平日カウント
  - `--:--` → 今日を含める
  - 数字あり → 今日を含めない
- ドラッグで移動可能なパネル UI

## ダウンロード・インストール

### 非開発者の方（ZIP でダウンロード）

1. [GitHub のリポジトリページ](https://github.com/takumaoguchi-creator/daily-hours-checker) を開く
2. 緑色の **Code** ボタンをクリック → **Download ZIP** を選ぶ
3. ダウンロードした ZIP ファイルを **解凍** する（ダブルクリックで OK）
4. Chrome で `chrome://extensions/` を開く
5. 右上の **デベロッパーモード** を ON にする
6. **パッケージ化されていない拡張機能を読み込む** をクリック
7. 解凍した **フォルダ** を選ぶ（ZIP ファイルそのものではなく、中身のフォルダ）

インストール後、ATND の勤怠ページを開くと右上にパネルが表示されます。

> **注意:** ZIP ファイルのままでは読み込めません。必ず解凍してください。

### 更新する場合

新しい ZIP をダウンロードして解凍し、`chrome://extensions/` で拡張機能の **更新（↻）** を押すか、一度削除してから再度フォルダを読み込んでください。

## ファイル構成

- `manifest.json` — 拡張機能定義
- `content.js` — ページ上の UI と計算ロジック
- `background.js` — 祝日 API からの平日計算
- `styles.css` — パネルスタイル
- `icons/` — 拡張機能アイコン
