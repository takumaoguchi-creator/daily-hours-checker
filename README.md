# 日割時間チェッカー

ATND 勤怠ページ（`https://atnd.ak4.jp/ja/attendance`）向けの Chrome 拡張機能です。  
残り月間所定不足時間を、今月の残り平日日数で割った **1日あたり必要時間** を表示します。

## 機能

- 残り月間所定不足時間の自動取得
- 祝日 API を使った残り平日日数の計算（土日・祝日除外）
- 今日の退勤打刻状況に応じた平日カウント
  - `--:--` → 今日を含める
  - 数字あり → 今日を含めない
- ドラッグで移動可能なパネル UI

## インストール

1. このリポジトリを clone する
2. Chrome で `chrome://extensions/` を開く
3. 「デベロッパーモード」を ON
4. 「パッケージ化されていない拡張機能を読み込む」
5. このリポジトリのフォルダを選択

## ファイル構成

- `manifest.json` — 拡張機能定義
- `content.js` — ページ上の UI と計算ロジック
- `background.js` — 祝日 API からの平日計算
- `styles.css` — パネルスタイル
- `icons/` — 拡張機能アイコン

## 開発

アイコンを再生成する場合:

```bash
python3 scripts/generate_icons.py
```
